### 口径

- 指数值本身无口径歧义，但**成交额单位是元**，前端要自己换亿。
- `index_spot.snapshot_kind` 分 `intraday`（盘中实时，只有 `spot_date` 是今天才可信）
  与 `close`（收盘快照，带成交额）。**盘前看到的「最新价」是集合竞价参考价，不可信** ——
  脚本已按三条判据（价格≤0 / 等于某历史收盘 / 成交额=0）跳过写库。
- 海外指数的**交易日历不同**：同一天 A 股有、美股可能还没开盘，反之亦然。
  不要用「最新一行是同一天」判断数据是否齐备。

### 频率与深度

- 历史：每日全量重拉（B 类窗口），上限 20 年；`index_prices` 实测最早 1996-03-11。
- 分时：**只能滚存**，`index_minutes` 从 2026-04-01 起累积。
- 实时快照：覆盖写，无历史。

### 当前覆盖（2026-11-10）

`market_indices` 80 个序列（AI硬件/A股/港股/航运/建材/美股/欧洲/亚太/资金流向 九类）；
`index_prices` 105,181 行；`index_spot` 9 行；`index_minutes` 141,006 行 / 6 指数。

| 项 | 结论 |

| **北向资金 2024-08-19 后无新值** | 港交所当日起**停止披露**北向每日净买入额。不是抓漏，是源侧停更 |

## 二、航运

### 2.1 CCFI 中国出口集装箱运价指数

- **源**：`https://www.sse.net.cn/index/singleIndex?indexType=ccfi`，服务端渲染，
  plain requests 即可，无需 JS、无需登录。**一次返回上期 + 本期两期**（含涨跌幅）。
- **口径**：基期 1998-01-01 = 1000；周频，每周五发布；13 条线（综合 + 12 航线）。
- **深度**：免费只有当期两期。历史 2023-04-21 起靠 GreenPacific 补（2,223 行）。
- **⚠ 历史是付费墙**：多期端点 `/index/mutipleIndex` 返回
  `{"success": false, "message": "对不起你没有登陆!"}`；POST 历史 `date` 返回空表。
  订阅价 CNY 15,000/年。
- **⚠ 合规**：上航所声明 SCFI/CCFI 数据仅供浏览，无书面许可不得转载/再分发/商用。
  内部研究可用，**对外发布前必须确认**。

### 2.2 BDI 系列

- **源**：`akshare.macro_china_freight_index()`，返回最近 5000 个交易日。
- **口径**：`bdi` `bci` `bsi` `bdti` `bcti` 五条。**这是本库少数「历史能直接回补」的源**。
- **深度**：2006-07 起，22,648 行。
- **主动放弃的序列**（都是死了十年以上的）：
  - `BHMI` 灵便型综合运价指数 —— **只有 1 行**（2009-01-28）
  - `HRCI` 国际集装箱租船指数 —— 212 行，**最后更新 2011-08-23**

### 2.3 CTFI 中国进口原油运价指数

- **源（当期）**：上航所 `singleIndex?indexType=ctfi`，服务端渲染。
- **源（历史）**：中华航运网（上航所授权转载）周报 `/Tanker/CTFIWeek/` +
  月报 `/Tanker/CTFIMon/`，正文直接引用官方值并给出航线级 WS/TCE。
- **抓什么**：综合指数 + CT1（中东湾→宁波，27万吨）/ CT2（西非→宁波，26万吨）/
  CT4（美湾 STS→宁波）/ 每条给 **指数点 · WS · 美元每吨 · TCE 美元每天（标准+经济航速）**。
- **深度**：月报 2021-09 ~ 2026-08（约 5 年）；周报 2025-07 ~ 2026-09（约 14 个月）。
- **⚠ 口径分层（最要紧）**：当日值（`ctfi_*`，662 行）与期间均值
  （`ctfi_*_month_avg` / `_week_avg`，616 行）**绝不能拼成一条序列** ——
  均值会把波动抹平后再接到点值上。
- **⚠ CT4 单位是「万美元」**（包干运费总额，权重 0% 不参与综合指数），不是指数点。
- **⚠ 负 TCE 真实存在**（2021-09 报「平均 -9 美元/天」），**不做 0 截断**。

#### 死路（CTFI 历史）

| 尝试 | 结果 |
|---|---|
| 上航所带 `date` 参数（GET / POST+CSRFToken） | 响应体字节级完全相同（26,731 字节、0 个数值）→ 服务端忽略 date |
| `/index/mutipleIndex` 传对 `startDate`+`endDate` | 仍返回「对不起你没有登陆!」 |
| 官方 FAQ | 非订购用户不能查历史；订购用户只能查**最近 3 年**，年费 1.5 万/指数 |
| ⇒ 结论 | **付费也拿不到 2013-11-28（发布日）以来全历史**，所以走免费的第二条路 |

## 四、AI 硬件

### 源站

| 块 | 站 | 单位 | 更新频率 |
|---|---|---|---|
| 存储颗粒 DDR5/DDR4 | `dram.com.cn`（中国IC交易网，深圳） | **美元/颗** | 日（周末无报价） |
| NAND 晶圆 | 同站 `sortid=3` | 美元/颗，容量 **Gb** | 周级 |
| SSD OEM（白牌） | 同站 `sortid=9` | 美元/个 | 周级 |
| SSD 零售品牌盘 | 同站 `sortid=5` | 人民币/个 | 日更 |
| HDD 机械盘 | 同站 `sortid=10` | 人民币/个 | **季度级**（半年 3~4 点） |
| GPU 云租价 | `aimultiple.com/ai-gpus` | **美元/卡·小时** | 日更 |

### 口径（三个陷阱，前端/接口都靠这三个字段区分）

1. **「颗粒价」≠「内存条价」**：`DDR5 16Gb(2Gx8)` 是 16Gb 颗粒 = 2GB，不是 16GB 内存条，
   量级差 8 倍。**每 GB 价 = 颗粒价 ÷ (Gb/8)**。
2. **`grade` 必须参与分组**：原厂正片（prime）与 eTT 白牌同规格相差 5~6 倍，合成一条曲线毫无意义。
3. **GPU 是每卡时租不是整机价**：源站 `$113.93 (x8 GPUs)` 是 p5 整机一小时价，
   直接当单卡会虚高 8 倍。落库前已 ÷ 卡数，`gpus_per_node` 留着还原总价。
   另有 `provider='market_min'` 是源站总表给的**单卡最低价**，不含整节点摊销 →
   会出现「最低 $3.67 但 Vultr 摊到 $3.20」，不是数据错。

### 深度

- **颗粒与成品只有滚动半年**（更早要站方买 Excel）→ 「错过就没有」，靠日更累积。
  当前 `dram_prices` 1,438 行 / 11 品种 / 2026-04-27 起。
- GPU 云租价 2026-10-26 起，90 条 / 6 型号 / 17 家。
- **报价日不连续**（周末无报价），查询端**不要按自然日补空/前值填充**。

### 死路

| 项 | 结论 |
|---|---|
| 光模块 / CPO 现货价 | **没有可抓的公开价**。FS.com 纯客户端渲染（页面里连 price 字段都没有）；Amazon 搜 800G 混进 400G 与 PoE 模块；Digi-Key/Mouser/eBay/新蛋全 403。ASP 只在 LightCounting/Yole 付费报告 → **不做**，页面写明原因 |

## 五、外汇

### 两个口径、两个源（**绝不混拼**）

| 口径 | `rate_type` | `source` | 源站 | 覆盖 |
|---|---|---|---|---|
| 人民币中间价 | `mid` | `cfets` | 中国货币网（受权发布） | **25 对**，2006-01 起，80,044 行 |
| 人民币即期 | `spot` | `sina` | 新浪外汇 | **19 对**，USDCNY 1994-08 起，29,951 行 |
| 即期实时快照 | — | `sina` | `hq.sinajs.cn/list=fx_s{ccy}cny` | 19 行，覆盖写 |

### 口径（唯一，全表适用）

`close` = **1 单位外币兑人民币**（CNY per 1 unit foreign）。

- `USD/CNY 6.7351` → 6.7351
- `100JPY/CNY 4.2727` → 0.042727（÷100）
- `CNY/KRW 201.70` → 0.0049579（取倒数）

**为什么统一**：CFETS 官方对 10 对报「外币/人民币」、对另 15 对报「人民币/外币」。
原样入库会让同一页出现两种方向（USD/CNY 上行=人民币贬值，CNY/KRW 上行=人民币升值），
涨跌红绿语义互相矛盾。统一后：**数值上行 = 人民币贬值（红）**，全表唯一。

`fx_pairs.quote_unit`（日元 100，其余 1）只管**展示倍数**，不改语义。

### 差异与深度

- **中间价**：每工作日 9:15 发布；周末/节假日**没有数据**（当天就没发，不是没抓到）。
  只有 close（官方只给单一中间价，没有开高低）→ **UI 上 OHLC 一律显示「—」**。

## 七、私募基金

> **先说结论**：私募和公募不是一个物种。公募那套「名录 / 规模 / 持仓 / 净值」四层，
> 私募**只有名录能全量对标**。《私募投资基金募集行为管理办法》禁止公开宣传推介、
> 禁止公开披露业绩 → 规模/持仓/净值在公开渠道拿不到，**这是监管口径，不是技术问题**。

### 7.1 备案名录（中基协，官方免费）

- 管理人：`POST gs.amac.org.cn/amac-infodisc/api/pof/manager` → 18,432 家
- 产品：`POST gs.amac.org.cn/amac-infodisc/api/pof/fund` → 251,491 只
- **字段只有备案级**：备案编码 / 名称 / 管理人 / 管理类型 / 运行状态 / 备案时间 /
  成立时间 / 托管人 —— **没有规模、没有净值、没有持仓**。
- **⚠ 频控**：连续十几次后持续 400/500，**等 30 秒也不恢复**（按 IP）。间隔锁 1.2 秒。
- **⚠ `page` 是 0-based**。文档曾写「从 1 开始」是错的（把频控的 400 误当语义限制），
  代价是系统性漏掉 page 0 那一页 —— 而 page 0 正是**全表最新**的 100 条。

### 7.2 净值：三源、两种口径

| `source` | 站 | `unit_nav` | `acc_nav` | 覆盖 |

1. **复权 vs 累计是两套口径**。有分红的产品终身收益最多差 2.5 倍，

## 九、VLCC 船队与船位

### 9.1 名录（两条线，口径不同，必须分开理解）

| 船东 | 源 | 口径 | 艘数 |
|---|---|---|---|
| 招商轮船 | `chinashipbuild.com` 船队库 | **在役**（`roster_asof` = 抓取当日） | 51（142 艘全船队按 DWT≥20万 剔除 8 艘阿芙拉） |
| 中远海能 | 官网《本集团自有油轮运力》PDF | **2021-06-30 官方快照**（不是「当前在役」） | 48 |

**⚠ 三条口径，别搞错**：

1. **名录口径 = 中国船东，不是挂旗**。这两家的 VLCC 大量挂中国香港旗 / 新加坡旗 /
   巴拿马旗 / 利比里亚旗，按「挂中国旗」筛会漏掉绝大多数。`flag` 列只做参考。
2. **`name_ais`（英文船名大写+折叠空白）是 AIS 匹配键**。AIS 只认船名/MMSI，不认船东 ——
   **名录不是装饰，它就是过滤器本身**。
3. **两个源都不给 IMO/MMSI**，由船位脚本 `--learn` 从 AIS `ShipStaticData` 反推回写并置
   `verified=true`。`verified=false` 只代表「还没被 AIS 实见过」，**不代表这船不存在**。

#### 为什么中远不换「当前在役」源（2026-10-01 定案，别再问）

公开渠道**根本不存在逐船名的中远在役清单**：

- 2025 年报（2026-03-26）只给「油轮 155 艘 / 2257.6 万载重吨」这类**船型汇总**；
- 券商研报（东方证券 2026-07-09）给「VLCC 41 自有 + 7 租入 / 1472 万载重吨」，**同样不给船名**；
- 船队库（chinashipbuild）只覆盖招商；
- 逐船名的在役库（Equasis / Miramar / Clarksons）都是付费产品，不在本项目口径内。

⇒ 硬凑一个「当前口径」只会引入来源不明的数据。**宁缺勿错**：
保留有出处的快照，把「它是什么口径」写进 `roster_asof`，
把「哪些已经不属于它了」写进 `roster_status`（4 艘已转手：COSBRIGHT→SUN I、
COSGLORY→FIRENZE K、COSGREAT→BIG MAG、COSGRAND→LILA JAMNAGAR）。

**名录死路**：招商官网 502/403/404；中远官网 plain HTTP 是 F5 WAF JS 挑战（只能 puppeteer，
且该 PDF 是历史存档件，脚本已内嵌常量快照）；MarineTraffic 403（Cloudflare + XHR 真数据）；
VesselFinder 超时/IP 封；船讯网恒返空（要登录态）。

### 9.2 船位（HiFleet 付费 = 主源）

- **当前覆盖**：99 艘名录中 **95 艘已配船位**，3,241 行，`source='hifleet'`。
  4 艘转手船已登记进脚本 `RETIRED` 表，**拦在匹配前**，不再搜索、不再查位。
- **计费**：实测查位 97 次扣 **0 点**（按小时结算），贵的是**时间**不是钱
  （一轮约 90 秒、95 次逐船查位）。
- **⚠ 为什么逐船查而不是 bbox 批量**：99 艘分布全球，bbox 要盖住整个印度洋+大西洋+太平洋
  才能捞全，既扫出几十万条无关船，又仍需本地过滤。逐船成本可预测、可对账。

#### ⚠ 单位陷阱（踩过，记档）

1. **位置接口 `la`/`lo` 单位是「分」不是「度」** → 必须 ÷60。
   官方原文：纬度 = `parseFloat(la) / 60`。不换算会把船放到 60 倍远的地方。
2. **`ti` 是 UTC+8**，库里 `ts` 存 UTC → 必须 −8h。否则全部船位显示成「8 小时后更新」。
3. **同一家 API 内部就不统一**：`gettraffic`（区域船舶）返回的 `lat`/`lon` 却是**度**。
   以后换接口必须重看单位，别信「同一家 = 同口径」。
4. **自检脚本**：`--selftest` 用官方样例报文做断言，**不花额度**。别靠肉眼「看地图像不像」。

#### 免费源为什么被降级（2026-09-30 实测定论）

aisstream.io 是**岸基志愿接收站拼起来的区域网，不是全球网**。窄 bbox 各采 30 秒：

```
北海(欧) 27.5 条/s   ← 全球订阅那 ~43 条/s 里六成来自这里
珠江口/香港 1.7   英吉利海峡 1.5   美东 1.4   墨西哥湾 1.3
地中海中部 0.5    中国东海 0.5    巴西 0.3    西非 0.2    台湾海峡 0.1
────────────────────────────────────────────────
波斯湾 / 红海曼德 / 阿拉伯海 / 马六甲 / 南中国海 / 上海长江口   全部 0 条/s
```

再用已学到的 MMSI 精确订阅（NEW WISDOM 477095600 / NEW DRAGON 477127300）4 分钟仍是 0 条
→ **不是限速、不是没 MMSI、不是 key 的问题，是当地没有接收站**。

而中国 VLCC 的主力航线（波斯湾装货 → 印度洋/红海 → 马六甲 → 南中国海 → 中国卸货）
几乎全在这片盲区。**所以免费源做不到「跟踪中国 VLCC 全球船位」**，
已降为副源（海外段补充 + 调研存档）。

**⚠ 方法论教训**：订一个全球框看到「有数据」≠ 目标区域有覆盖。
选源**必须用目标区域窄 bbox 单独测密度**，看「目标对象命中数」，不看总量。

### 9.3 船位时间语义

`ts` 是 **AIS 报文时间（UTC）**，不是我们收到的时间。远洋船没有岸基覆盖时，
最新报文可能已过去几小时甚至几天 —— **这是 AIS 的固有限制，不是数据坏了**。
前端必须显示「更新于 X 小时前」，不能默认所有点都是实时的。

### 已知缺口与偏差

- **北交所不覆盖**（明确排除，不是抓漏）。
- **`quote_time`（东财 `f124`）不是成交时刻**：339 只停牌/退市/ST 股返回当日 08:00:00 占位，
  **不能用它判断「最后交易日」**。
- **员工数只有当前快照**：季报不披露，源侧只有 `RPT_F10_BASIC_ORGINFO.EMP_NUM`，
  无报告期字段 → 一年存一条逐年累积，**不要宣称「逐季度员工数」**。
- **股东户数 `END_DATE` 是统计截止日**，不必等于季末（茅台 64 期里 02 月 6 期、04 月 1 期）
  → 映射季度取「该季内最后一个 end_date」，**不硬凑季末**。
- **2018~2021 乳品/部分历史缺口**、**财报只到 2016 起**（源侧 1990 就有，
  要更早用 `--since 1990-01-01 --full`）。
